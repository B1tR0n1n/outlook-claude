CLAUDE / OUTLOOK

A Claude button for classic Outlook. Summarize, find action items, draft replies, rewrite drafts.

COM ADD-IN (ON-PREM EXCHANGE: USE THIS)

Installs on your PC, not on the mail server, so Exchange can't block it. No admin rights. Outlook 2016 or later on Windows 10/11.

Download ClaudeOutlook-COM.zip
  1. Right-click the zip → Properties → tick Unblock if it's there → OK. Then Extract All.
  2. Close Outlook. In the extracted folder, double-click install.cmd. If Windows says it protected your PC: More info → Run anyway.
  3. Start Outlook. The Claude group is at the right end of the Home tab.
  4. Claude → Settings: paste your Claude API key (starts sk-ant-api03-), click Test Connection, then Save.

OFFICE ADD-IN (EXCHANGE ONLINE / SERVER ALLOWS IT)

Download manifest.xml
  1. Save manifest.xml with the button above (if it opens as text instead, right-click the button and choose Save link as).
  2. In Outlook: File → Manage Add-ins. On an on-prem Exchange server this opens a page in your browser.
  3. Click + → Add from file…, choose manifest.xml, then Install.
  4. Restart Outlook. Open an email: Claude is on the Home ribbon. When writing, it's on the Message ribbon.
  5. On first open, paste your Anthropic API key in the panel and Save.

No "Add from file"? Your Exchange admin has blocked self-installed add-ins and has to install it for you. Source and admin command: github.com/B1tR0n1n/outlook-claude

THUNDERBIRD (LINUX, MAC, WINDOWS; PROTON MAIL VIA BRIDGE)

The same buttons in Thunderbird 128 or later: Claude on the message toolbar when reading, and on the compose toolbar when writing.

Download claude-thunderbird.xpi
  1. In Thunderbird: ☰ → Add-ons and Themes → gear icon → Install Add-on From File… → claude-thunderbird.xpi → Add.
  2. Open an email and click Claude on the message toolbar. A Claude window opens. On first run, paste your Claude API key (starts sk-ant-api03-) and Save.
  3. When writing, click Claude on the compose toolbar. Select text to work on just that, or leave nothing selected to rewrite your part of the draft. The quote and signature are kept.
  4. Proton Mail: Thunderbird reaches it through Proton Mail Bridge (paid plans). Mail you run Claude on leaves Proton's encryption and goes to Anthropic.

NO ADD-IN ROUTE: MACROS

Exchange won't take add-ins? The same features as Outlook VBA macros. No Exchange, no admin rights.

Download ClaudeOutlook.bas
  1. In Outlook press Alt+F11. In the VBA editor: File → Import File… → ClaudeOutlook.bas.
  2. Still in the editor, press F5 on Claude_SetKey (or Alt+F8 in Outlook) and paste your API key.
  3. Add buttons: File → Options → Customize Ribbon → Choose commands from: Macros. Put the reading macros (Summarize, DraftReply…) on the Home tab, and the writing ones (Improve, Shorten…) on the New Mail tab.
  4. If macros won't run: File → Options → Trust Center → Trust Center Settings → Macro Settings. If it's set to signed macros only, sign the project with SELFCERT.EXE (in the Office folder), then Tools → Digital Signature in the VBA editor.
