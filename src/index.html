CLAUDE / OUTLOOK

A Claude button for classic Outlook. Summarize, find action items, draft replies, rewrite drafts.

Download manifest.xml
  1. Save manifest.xml with the button above (if it opens as text instead, right-click the button and choose Save link as).
  2. In Outlook: File → Manage Add-ins. On an on-prem Exchange server this opens a page in your browser.
  3. Click + → Add from file…, choose manifest.xml, then Install.
  4. Restart Outlook. Open an email: Claude is on the Home ribbon. When writing, it's on the Message ribbon.
  5. On first open, paste your Anthropic API key in the panel and Save.

No "Add from file"? Your Exchange admin has blocked self-installed add-ins and has to install it for you. Source and admin command: github.com/B1tR0n1n/outlook-claude
